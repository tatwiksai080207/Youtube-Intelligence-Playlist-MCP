### `draft_curated_playlist`

**Description:** Discover candidate videos and build an immutable, expiring constrained playlist draft without modifying YouTube (FR-5.1, FR-5.1a, FR-5.2, FR-5.3, FR-6.2, read only).

- **SRS Requirements:** `FR-5.1, FR-5.1a, FR-5.2, FR-5.3, FR-6.2`
- **Side Effects:** Creates an immutable, expiring local draft in SQLite (no YouTube writes)
- **Quota Cost:** Preflights worst case 50 + 50 * max_videos units; charges only actual discovery search and video list calls (100 search units + candidate batches)

#### Input Arguments

| Argument | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `topic` | `string` | Yes | min length: `1`; max length: `300` | Topic or learning query used to search and rank candidate videos. |
| `target_total_minutes` | `number` | Yes | min: `1`; max: `600` | Target total duration T in minutes; valid drafts stay within [T * (1 - tolerance), T] and never exceed T. |
| `tolerance_percent` | `number` | No | default: `5.0`; min: `0.0`; max: `50.0` | Allowed percentage below target_total_minutes (default 5.0 percent; total duration never exceeds target_total_minutes). |
| `max_video_minutes` | `number` | No | min: `1`; max: `600` | Optional inclusive maximum duration per individual video in minutes. |
| `max_videos` | `integer` | No | default: `25`; min: `1`; max: `50` | Upper bound on the number of selected videos (default 25; never treated as an exact required count). |
| `language` | `string` | No | min length: `2`; max length: `35`; pattern: `^[A-Za-z]{2,3}(?:-[A-Za-z0-9]{2,8})*$` | Optional BCP 47 spoken language code checked solely on primary subtag against snippet.defaultAudioLanguage. |

| `title` | `string` | No | min length: `1`; max length: `150` | Optional title proposed for the playlist draft shown during trusted confirmation. |
| `privacy_status` | `string (`private`, `unlisted`, `public`)` | No | default: `private` | Playlist privacy setting to apply upon confirmed creation (default private). |

## MCP Resources

Resources allow MCP hosts to inspect live server metrics and aggregated user context over read only URIs without consuming YouTube API quota.

### `youtube://metrics/quota`

**Resource Name:** Daily Quota Metrics  
**MIME Type:** `application/json`  
**Description:** Real time daily quota usage, remaining limits, and reset timestamp for units and search calls.  
**Quota Cost:** 0 units (purely local read)

#### JSON Payload Fields

| Field | Type | Description |
|---|---|---|
| `units.limit` | `integer` | Configured daily quota units limit (default 10,000) |
| `units.used` | `integer` | Cumulative units consumed during the current Pacific Time day |
| `units.remaining` | `integer` | Remaining units available before upstream exhaustion |
| `search_calls.limit` | `integer` | Configured daily search.list calls limit (default 100) |
| `search_calls.used` | `integer` | Search calls dispatched during the current Pacific Time day |
| `search_calls.remaining` | `integer` | Remaining search calls available before exhaustion |
| `reset_at` | `string` | ISO 8601 timestamp of the next midnight Pacific Time reset |
| `timezone` | `string` | Quota tracking timezone (America/Los_Angeles) |

---

### `youtube://user/context`

**Resource Name:** User Context and Topic Profile  
**MIME Type:** `application/json`  
**Description:** Aggregated user context with zero PII, including channel ID, signal counts, and topic interest distribution.  
**Quota Cost:** 0 units (cached/local aggregate read)

#### JSON Payload Fields

| Field | Type | Description |
|---|---|---|
| `channel_id` | `string` | Authenticated YouTube channel ID or empty string |
| `has_channel` | `boolean` | Whether the authenticated user owns a YouTube channel |
| `total_signals` | `integer` | Total engagement signals aggregated across subscriptions, playlists, and likes |
| `subscriptions_count` | `integer` | Number of active channel subscriptions |
| `playlists_count` | `integer` | Number of user created or saved playlists |
| `liked_videos_count` | `integer` | Number of liked videos accessible in personal library |
| `topic_distribution` | `object` | Map of topic categories to normalized interest weights [0.0, 1.0] |
